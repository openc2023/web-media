# 个人主页

走老电脑屏幕的路子：黑底、电光蓝的抖动点阵、等宽排版与框线字符。头图是从点阵场里“刻”出来的「田漢」。中文 / English / 한국어 三语。

| 文件 | 内容 |
| --- | --- |
| `../../index.html` | 页面骨架，放在仓库根目录，让主页地址保持最短 |
| `index.html` | 跳转页，旧链接 `personal/home/` 会回到根目录主页 |
| `data.js` | 三语文案，本页唯一的内容来源；`shared` 放三语共用的年份、链接与联系方式 |
| `hero.js` | 头图字符场，四种渲染：`dither` 方点有序抖动、`halftone` 印刷网点、`ascii` 字符梯度、`braille` 盲文细点；光标移动点亮，点击起涟漪 |
| `bgfield.js` | 全页背景字符场：稀疏漂移点阵，光标附近照出字符，滚动有视差、越快越亮 |
| `bg-works.js` | 作品页（TOP、山海）复用 `bgfield.js` 的入口：常亮、主页电光蓝；TOP 打开相机时自动关掉 |
| `fx.js` | 文字解码效果：栏目标题进入视口、切换语言、悬停链接时由乱码收敛成原文 |
| `main.js` | 渲染、语言与主题切换、数字键跳转、底部命令行、阅读进度、当前栏目高亮、论文筛选、开场 |
| `style.css` | 明暗两套配色，变量在 `:root` |

## 交互

- 首次打开会播一段终端开场（每个浏览器会话一次，点击或按键可跳过）。
- 往下滚动时头图溶解成稀疏点阵，背景字符场接上；顶栏的框线随阅读进度变色。
- 论文栏的 `$ grep` 可按年份、标题、学会筛选，命中部分高亮。
- 数字键 `1`–`8` 跳到对应栏目，`M` 切换头图渲染方式，`/` 聚焦底部命令行。
- 命令行支持 `help`、栏目名、`zh` / `en` / `ko`、`light` / `dark`、`dither` / `halftone` / `ascii` / `braille`、`whoami`、`clear`。
- 语言、主题和渲染方式记在浏览器本地；首次访问按浏览器语言选择。

## 修改

- 改文字：只改 `data.js`，三种语言的字段结构保持一致；论文的年份和获奖标记在 `shared.papers`。
- 换头图字形或位置：`main.js` 里的 `glyph` 与 `layout`；配色在 `style.css` 的 `--g1`、`--g2`。
- 纯静态页面，不需要构建；直接打开仓库根目录的 `index.html`，或从根目录起静态服务器。
- `data.js` 里作品链接相对于仓库根目录书写（例如 `personal/works/top/`）。
