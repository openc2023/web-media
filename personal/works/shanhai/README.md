# 山海 · 生成式山水

山脊从卷底升起，越往上越平缓，到卷顶归于一线，再从卷底重新长出。同一套山脊模拟可以用四种方式呈现：

| 键 | 风格 | 做法 |
| --- | --- | --- |
| 1 | 水墨 Ink | 原作，算法、配色与参数保持不变 |
| 2 | 字符 ASCII | 由山脊几何算浓度：脊线按坡度用 `/` `\` `_`（浓墨），往下的雾用字符梯度（淡墨），偶尔浮出赭金的「山」「海」；卷底是 `~` 的海 |
| 3 | 点阵 Dither | 同一浓度场做 4×4 有序抖动，脊线浓墨点、雾与海淡墨点 |
| 4 | 青绿 Azure | 同一套模拟换成石青、石绿，山脚晕一层与题字同色的赭金；卷底加几道水纹 |

釜山实时天气（Open-Meteo，每 10 分钟更新）在字符、点阵、青绿里参与画面：风速决定山脊上升的速度，湿度决定墨迹残留的时间。水墨不受影响；离线时按默认参数运行。
