# 山海 · 生成式山水

山脊从卷底升起，越往上越平缓，到卷顶归于一线，再从海中重新长出。同一套山脊模拟有五种材质，切换时画卷的底、颜料和展厅强调色一起换：

| 键 | 材质 | 做法 |
| --- | --- | --- |
| 1 | 水墨 Ink | 原作，算法、配色与参数保持不变 |
| 2 | 青绿 Azure | 绢本金碧：同一模拟换石青、石绿，脊线勾金，正片叠底在绢色上；卷底石青水纹 |
| 3 | 字符 ASCII | 琥珀色旧屏：黑底、扫描线、字符微光；脊线按坡度用 `/` `\` `_`，雾里偶尔浮出「山」「海」 |
| 4 | 孔版 Riso | 双色孔版印刷：靛蓝山脊、赭黄雾气，两版正片叠底，黄版略错位，个别网点漏印 |
| 5 | 夜山 Night | 水墨画布反相后染成月光蓝，天色压成深靛，加月与星 |

字符与孔版由山脊几何算浓度（脊线最浓、往下如雾淡出），其余三种直接用模拟画布。

釜山实时天气（Open-Meteo，每 10 分钟更新）在水墨以外的材质里参与画面：风速决定山脊上升的速度，湿度决定墨迹残留的时间；离线时按默认参数运行。

页面像展厅：左下是展签（作者、作品名、媒介、说明、天气），中间是画卷，右侧是材质面板；窄屏依次为画卷、材质、展签。

- 点击画面重新起山；`1`–`5` 切换材质，`M` 轮换；`S` 开关声音（`shanhai.mp3`，浏览器要求先与页面交互才能播放）。
- 文件：`index.html` 页面，`style.css` 样式，`shanhai.js` 模拟与渲染；`山海.png`、`诗.png`、`7logo.png` 为画面上的题字、诗句与印章。
