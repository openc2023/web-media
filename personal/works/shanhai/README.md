# 山海 · 新媒体艺术交互项目

以山海意象、动态视觉与声音为主题的 Web 艺术作品，使用 HTML、CSS、JavaScript 与 Canvas。

- [作品入口](index.html)
- [个人主页](../../home/)

`index.html` 为作品页，`shanhai.mp3`、`山海.png`、`诗.png`、`7logo.png` 为页面素材。历史版本与视觉实验已从仓库移除，需要时可在 git 历史中找回。

从仓库根目录运行 `python -m http.server 8080 --bind 127.0.0.1`，访问 <http://localhost:8080/personal/works/shanhai/>。音频播放可能需要先点击页面。
