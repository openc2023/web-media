# 山海 · 生成式山水

山脊从卷底升起，越往上越平缓，到卷顶归于一线，再从卷底重新长出。同一套山脊模拟可以用四种方式呈现：

| 键 | 风格 | 做法 |
| --- | --- | --- |
| 1 | 水墨 Ink | 原作算法直接画在宣纸色画布上，残影形成墨晕 |
| 2 | 字符 ASCII | 由山脊几何算浓度：脊线按坡度用 `/` `\` `_`，往下的雾用字符梯度，偶尔浮出「山」「海」 |
| 3 | 点阵 Dither | 同一浓度场做 4×4 有序抖动 |
| 4 | 线描 Line | 山脊每上升一段留下一条轮廓，前面的山遮住后面的，叠成层层等高线 |

釜山实时天气（Open-Meteo，每 10 分钟更新）参与画面：风速决定山脊上升的速度，湿度决定墨迹残留的时间。离线时按默认参数运行。

- [作品入口](index.html) · [个人主页](../../../index.html)
- 点击画面重新起山；`M` 轮换风格；`S` 开关声音（`shanhai.mp3`，浏览器要求先与页面交互才能播放）。
- 文件：`index.html` 页面，`style.css` 样式，`shanhai.js` 模拟与渲染；`山海.png`、`诗.png`、`7logo.png` 为画面上的题字、诗句与印章。
