# 4 · X光镜 v0.3.1

鬼神系列 04。镜子里只剩骨头——然后骨头也不对劲了。

## 多人与近距离（v0.3.1）

- **近距离阈值**（设置 → 异常，按脸宽，默认 0.12）：只有比它更近的人才走剧情，远处的人只显示普通骨头。进入要 ≥ 阈值、退出要 < 阈值 85%，站在边界上不会来回跳。
- 走到一半退远：剧情暂停；一直不回来超过“退远多久后重来”（默认 3 秒）就从头开始。已经在显形 / 断讯的人会把这一段演完。
- **同时显形最多人数**（默认 2）：名额满了，其余的人停在“体征异常”末尾排队，离得近的先。
- **开始前随机等待**（默认 0–3 秒）：几个人不会同时开始变异。
- 调试叠加里每个人头上显示 NEAR / far、阶段、排队（queue）。演示模式里的人会前后来回走，用来看这些规则。

## 异常剧情（v0.3.0 新增）

每个被追踪的人独立走一遍，人离开就重来：

| 阶段 | 画面 | 默认时长 |
| --- | --- | --- |
| 平静 | 旧胶片骨白色的 X 光，体征正常，心跳声 | 6 s |
| 体征异常 | 心率越来越慢、后半段乱跳（偶尔猛蹿），体温往下掉、血氧下降；卡片转红，标 ANOMALY；骨头偏红、亮度发抖 | 6 s |
| 显形 | **无生命体征**、平直长鸣；眼眶变黑洞（里面一点红光）并流下黑泪；额头裂痕往外长；肩后伸上来一只不属于任何人的手骨 | 7 s |
| 断讯 | 这个人的解剖消失，头部区域变成雪花 + `SUBJ xx · SIGNAL LOST`，整个画面撕裂一下、静电声 | 2.5 s |

- 每轮各阶段时长随机 ±30%，裂痕形状、手骨在左还是右每轮重新随机，几个人不会同步。
- 设置 → 异常：开关、四个时长、每轮随机差异、重新开始；黑眼洞 / 裂痕 / 手骨分别开关；骨骼配色（旧胶片骨白 / 医疗蓝原版）；音量。
- 声音在第一次点击或按键后才会出（浏览器规定）。几个人同时时只按剧情走得最远的那个人出声。
- 调试叠加（识别 → 检测叠加）会在每个人头上显示当前阶段和进度。

## 之前的版本

修复用户确认的透视镜问题：指尖模式移除人脸、鼠标及画面中心回退。无确认手部时隐藏透视窗口、圆圈及其解剖标注，手离开后不会把圆圈放到脸上。

修复：模拟手骨默认关闭，演示模式明确标为 DEMO 并提供返回实拍入口。实拍手部使用较高置信度、连续确认与最小尺寸过滤；无结果、检测报错和视频停帧后清除旧手骨。识别页新增手部参数。校准数值输入可超出滑块范围，自动扩展上下限，刷新后保留；缩放值必须大于零。

从用户提供的 X-Ray Mirror 单页改造，界面沿用前三个互动 demo 的深色等宽字体、340px 右侧设置抽屉、彩色参数、分组编号和中／英／韩切换。

## 本地运行

- 双击 `start.bat`（需要已安装 Node.js），或在此目录执行 `node server.cjs`。
- 摄像头入口：http://localhost:8130/
- 无摄像头演示：http://localhost:8130/#demo
- 服务仅监听本机 127.0.0.1，不开放局域网。手机真机使用须另行部署 HTTPS；普通局域网 HTTP 不保证可使用摄像头。
- S 打开／关闭设置；Esc 关闭；F 切换全屏；P 切换摄像头／演示页面。
- 手机：右上角连点三下，或双指按住 1.2 秒。侧栏可滚动；主画面固定。
- 设置在此浏览器保存；localhost 与 127.0.0.1 是不同来源，保存内容互相独立。

## 功能

保留头骨、脑部、肌肉、眼球、头部轮廓、手骨、解剖标注、X 光／实体材质、真人透出、边缘羽化、半边切割、指尖透视镜和头部校准。设置分镜头、识别、解剖、画面、校准五页，滑块支持直接输入数值。

实拍直接作为背景，默认真人透出为 1。主画面保留摄像头比例，剩余区域为黑色；电脑设置栏在画面旁，手机设置在画面下方。镜头支持设备选择、480p／720p／1080p／4K 请求分辨率、0／90／180／270° 旋转及镜像；设备或分辨率改动后点“应用摄像头设置”。实际分辨率以设备返回值为准，默认请求 1280×720。

人数可调 1–6，每人独立模型与跟随状态；支持最小脸宽、置信度、平滑、丢失容忍、检测频率和挑人优先级。采用匿名空间匹配，交叉或遮挡后仍可能换号，不是身份识别。手骨仍为整幅画面最多两只。

画面支持灰调监控、老式彩色、原始画面、自定义四种风格；可调饱和度、曝光、对比度、暖色偏移、柔化、噪点、扫描线、暗角及偶发信号干扰。识别模型始终读取未滤镜的旋转原图。

模拟体征包括随机心率、呼吸、血氧、体温和动态波形，明确标记“模拟数据”，不是实际测量。卡片避开头部及其他卡片，空间不足则隐藏部分卡片。解剖标注及底层详细错误保留原始英文。

Three.js、MediaPipe JS／WASM 已置于 `vendor/`，手部模型位于共享 `../models/hand_landmarker.task`，人脸模型沿用 `../models/face_landmarker.task`。完整保留这些文件即可本地加载，无需 CDN。视频在浏览器本机处理。
