# 1 · 破碎鬼镜（깨지는 귀신 거울）v0.2

屏幕当镜子。有人靠近、正脸看镜子，镜子慢慢“坏掉”：四周结霜、出现污痕和随机裂痕，然后裂痕长到脸上，镜中的脸做出跟本人对不上的表情。**不会整面碎掉。**

## 运行

1. 双击 `start.bat`，会打开 `http://localhost:8123/`，自动开摄像头（摄像头只能在 localhost 或 https 下用）。
2. 画面上没有任何界面。按 **S**，或者**连点右上角三下**，打开设置。
3. 第一次需要联网：MediaPipe 从 jsdelivr 下载，人脸模型从 storage.googleapis.com 下载。
4. 浏览器要求先有一次点击或按键，声音才会开始。
5. 手机 / 平板：右上角连点三下，或两指按住屏幕 1.2 秒，打开设置；设置 → 演出 → 测试 里有“全屏 / 退出全屏”和“关闭设置”。画面固定不能滚动、缩放，长按不弹菜单；屏幕保持常亮（浏览器支持时）；摄像头断开会自动重连。

| 按键 | 作用 |
| --- | --- |
| S / Esc | 打开 / 关闭设置 |
| D | 识别叠加（脸框、脸宽 w、yaw、smile、level） |
| P | 模拟有人（没人也推进演出，用来看镜面效果） |
| R | 重置演出 |
| F | 全屏 |

## 演出（随 level 0→100% 逐步加深）

合格的人在镜前时 level 上升（默认 30 秒到满）。人离开后按“离开后消退”时间慢慢退回去，退到 0 时重新随机下一轮的位置。

| level | 层 |
| --- | --- |
| 0–60% | 四周冰霜，从边缘往里长，前沿不规则 |
| 8–70% | 污痕逐个出现：油污擦痕、往下流的痕迹、霉斑（手印已去掉，之后换成提供的素材） |
| 12–82% | 镜面随机位置出现裂痕，咔嚓声 + 轻微震动，裂纹慢慢蔓延 |
| 45–80% | 脸上裂痕：沿人脸关键点走出路径，跟着脸动 |
| 60–95% | 反向表情：本人不笑 → 咧嘴怪笑、眼睛睁大；本人在笑 → 嘴角下拉、眉心压低 |
| 85–100% | 黑眼 |

低频嗡声和结霜细响的音量跟着 level 变化。

## 鬼脸贴图（MediaPipe 官方 UV）

- `assets/canonical_face_model.obj`：MediaPipe 官方人脸模型（google-ai-edge/mediapipe 仓库），468 顶点、898 三角面。已转成 `assets/face_uv.json`（每个关键点的 UV、三角面、模型顶点）。
- 贴图：`face_base.webp`（静态底图）、`face_blink.gif`（眨眼，6 帧）、`face_veins.gif`（绿色血管，6 帧）。都按官方 UV 布局绘制，已叠网格核对过对位。
- 用 WebGL 按当前关键点把贴图贴到每个人脸上，开深度测试（转头时鼻子挡住远侧脸颊），轮廓边缘渐隐。GIF 用 ImageDecoder 逐帧解码循环播放。手挡住的地方用分割的“身体皮肤 / 衣服”扣掉。
- 进度 50–80% 显形，显形过程会闪；此外每人每 2.5–8 秒来一阵频闪（显形前也会偶尔闪出来），信号毛刺的瞬间也闪现。85% 的人会出贴图，三张贴图随机分配（演出 → 脸部 → 贴图 可固定）。
- **闪到屏幕前**：有人在镜前时，每 7–18 秒随机把鬼脸整张贴到屏幕正中频闪一下，配毛刺、震动和尖响。
- **对位校准**：三张贴图画的黑眼洞都比官方 UV 的眼睛低约 4%，两个 GIF 的嘴高约 1.6%。加载时自动测出每张图的黑眼洞和嘴的位置，只在眼睛、嘴附近平滑地挪 UV。剩下的误差用 演出 → 脸部 → 贴图上下 / 贴图缩放 微调。
- **面具外扩**：脸部轮廓外加一圈网格，往上扩得多（带出头发），两侧几乎不扩（不带出耳朵），最外圈渐隐。演出 → 脸部 → 面具外扩。
- **去背景**：贴图加载时从四边洪水填充出背景（底图浅灰底、GIF 黑底），设成透明并收边羽化，脸边不会露出背景色白边。
- **边缘渐变**：按每个顶点离面具外缘的远近算透明度，从外往里平滑变不透明。演出 → 脸部 → 边缘渐变（越大越软）。
- **锁嘴**：张嘴时把嘴附近的网格往中间收，面具的嘴保持闭合，不被拉扯；张合的位移平滑分摊到下巴和脸颊。演出 → 脸部 → 锁嘴（1 = 完全闭合）。
- **脸上裂纹 GIF**（`face_cracks.gif`，透明底、9 帧）：不是 UV 布局，按两眼和嘴的位置用仿射映射到网格上；进度 45–80% 按进度一帧帧长出来，长满后轻微“呼吸”。每个人随机一种颜色（血红、病绿、青、紫、黑、暗金）。
- 程序画的效果（怪笑变形、惨白、黑眼、程序裂纹、底光）已停用、从面板移除，脸上只用提供的贴图和裂纹 GIF；代码还保留着。
- 换贴图：同样按 MediaPipe UV 布局画好放进 `assets/`，在 `app.js` 的 `FACE_TEX` 里加一行。
- “模拟有人”且没检测到真脸时，会用官方模型顶点生成一张会转动的假脸，可以在没人时预览整套脸部效果。

## 待机吸引（没人时）

- 边缘一直留少量冰霜，前沿慢慢“呼吸”；3 块污痕在边缘慢慢出现、移动（流痕往下淌）、消失，再换位置。
- 信号毛刺：横向错位条、红青分离、扫描线、噪声条、偶尔整屏闪暗，配一声静电。没人时 2–6 秒一次、更强；演出中 5–14 秒一次、更弱。
- 设置：演出 → 待机吸引（边缘常驻强度、信号毛刺开关、毛刺频率）。

## 多人与随机面相

- 最多识别 5 张脸。识别 → 人数 → 同时作用人数（默认 3），按脸大小（离镜子近）排前几个人各自出效果。
- 每个人有自己的进度：后来的人从头开始，不受先来的人影响。镜面层（冰霜、污痕、镜面裂痕）仍按“有没有合格的人”整体推进。
- 每个新出现的人随机分到一种面相：尸白冷光、发绿病态、发红血色、手电暖光；光从左下 / 正下 / 右下随机；各阶段提前或推后一点；是否怪笑、是否黑眼、脸上裂痕 2–4 条也随机。
- 光色可以在 演出 → 脸部 → 光色 固定成某一种，默认“随机”。

## 脸部效果的防抖和遮挡

- **防抖**：关键点用 One Euro 滤波，整张脸共用一个截止频率（按鼻尖速度算），平滑时脸形不变形；静止时更稳，快速移动时自动放开。参数在 识别 → 脸部追踪 → 防抖（越小越稳）。
- **遮挡**：脸上裂痕先裁到脸部外轮廓里，再用 MediaPipe 多类分割（selfie_multiclass）只保留“脸部皮肤”像素，所以头发、手、眼镜挡住的地方不会画上裂痕。分割只在脸部裂痕阶段才跑。打开“显示关键点”可以看到遮罩。分割模型加载失败时，退回到只按脸轮廓裁剪。
- 反向表情是直接扭曲摄像头画面，所以天然有正确的遮挡关系；黑眼目前不受遮罩影响。

## 远距离检测

- 识别 → 距离 → **远距离检测**：关 / 2×2 / 3×2。摄像头离人远、脸很小时打开：画面切块轮流检测，已找到的小脸每帧在附近裁一块跟踪。近距离阈值同时调到 0.03–0.05（最低 0.02）。更吃性能。
- 低头、只露头顶的人检测不到。

## 识别规则

| 条件 | 处理 |
| --- | --- |
| 远处有人（脸宽 < 阈值） | 不推进 |
| 近处，正脸到左右 45° | 推进 |
| 近处，超过左右 45° | 停住，不推进也不回退；脸上效果继续跟着 |
| 多人 | 只选合格人中最近的一个；别人要大 15% 以上才换人，换人后脸上裂痕重新生成 |
| 人脸短暂丢失 | 丢失容忍时间内停住，脸部效果淡出，避免闪烁 |

45° 是自己设的过滤阈值，不是 MediaPipe 的识别极限。

## 设置面板（照 dev UI 的样式）

- **镜面**：选摄像头（含“测试画面”）、720p/1080p；镜子角度：0/90/180/270 旋转（摄像头竖装时用，识别也按转正后的画面做）、±20° 微调、铺满/完整、缩放、偏移、左右镜像、上下翻转；画面：亮度、对比度、饱和度、玻璃反光、暗角。
- **识别**：近距离阈值、角度上限、丢失容忍、离开后消退、调试叠加、关键点。
- **演出**：到满级时间 + level 条；冰霜、污痕、随机裂痕（数量）、脸上裂痕、反向表情（强度）、黑眼的开关；音量、低频氛围；测试按钮。
- 中 / EN / 한 三种语言。所有设置存在这台电脑的浏览器里（localStorage）。

## 已测 / 未测

- 已测（内置浏览器 + 测试画面）：页面和模型加载、设置面板、冰霜 / 污痕 / 随机裂痕随 level 推进。
- **未测：真人脸上的裂痕、反向表情、黑眼、45° 过滤、多人选人**。内置浏览器不能开摄像头，需要在 Chrome 里用真摄像头确认。
- 近距离阈值还没按现场摄像头标定。
- 不能离线用（模型从网上加载）。
