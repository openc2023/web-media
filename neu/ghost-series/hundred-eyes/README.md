# 5 · 百眼墙 v0.3.2

鬼神系列 05。

用户素材与参考图驱动的本地网页原型。两种眼睛固定随机混合；人靠近时整面闭眼，远离或离开后随机、错峰苏醒。实拍空间始终在底层，眼睛与更透明的运动水幕叠在前方。

## 运行

双击 `start.bat`（需 Node.js），或在此目录执行 `node server.cjs`。

- 实拍：http://127.0.0.1:8131/
- 无摄像头预览：http://127.0.0.1:8131/#demo
- S：设置；F：全屏；P：模拟靠近；Esc：关闭设置。
- 手机：右上角连点三次或双指按住 1.2 秒；真机摄像头需 HTTPS。
- 本机服务只监听 127.0.0.1。线上：https://openc2023.github.io/web-media/neu/ghost-series/hundred-eyes/

## 画面（v0.2：按参考图重做）

一遍 WebGL 合成（`membrane.js`），从后往前五层：

1. **空洞后面的空间**：实拍画面（模糊、去色、冷青色调、起雾），上面半透明叠一层程序画的雾中格子窗和红梅（“窗花不透明度”，默认 0.32）；中间一圈眼睛和肉膜也稍微透明（“中间透出实拍”，默认 0.45），能隐约看见摄像头画面；没有摄像头时窗花叠在暗雾上。设置 → 画面 → 空洞后面：自动 / 实拍 / 窗格。
2. **湿润的肉膜**：铺满眼睛之间，中间挖出一块空洞。起伏由每只眼睛周围鼓起的眼眶决定，再加皮肤细纹；左上冷光打出湿亮高光，空洞里也蒙着一层很薄的湿膜。
3. **眼睛**：72 只（10–160 可调），大眼先放、小眼补缝，铺满整个画面、边上可以出画，眼眶可以挤在一起（“挤压重叠”），中间空洞只偶尔漏进一两只小眼。两种素材（湿润眼 / 浑浊眼）按比例混合；每只眼睛轻微呼吸起伏。亮度、饱和度在着色器里统一调。
4. **水痕**：从上面流下来的黏稠水流，停在随机高度，末端挂一颗水珠慢慢往下坠；粗细一鼓一鼓地往下走，中间亮、边缘暗，会折射后面的眼睛和肉膜。有人靠近（闭眼）时流得更急。
5. **前景水墙**：最前面一层半透明的流动水（`assets/water-wall.png`，只取中间、边缘波浪白边不进画面），noise 扭动 + 焦散高光。“前景水墙不透明度”默认 0.3，“水墙流速”0.8。

相同随机种子 + 相同画面尺寸 → 同样的布局。原始 GIF 保留，`extract_frames.py` 只把帧原样解出来；浏览器加载时抠掉边缘背景。`reference-layout.png`（参考图）和原始 GIF 不参与运行，也不上传网站。

性能：在本机内置浏览器约 25 帧（程序上限 30）。之前给每只眼睛单独加 canvas 滤镜会掉到 10 帧，已改到着色器里。

## 多人：分区闭眼（v0.3.2）

- 每个人身后那一片眼睛先闭：人的脸宽超过“开始影响的脸宽”（默认 0.045）就出现一片，越近越大，到“靠近脸宽比”时半径为画面宽 × “分区大小”（默认 0.42）。区里的眼睛从中心往外依次闭上。
- 任何一个人近到“靠近脸宽比”（默认 0.14），整面墙闭眼（原来的规则）。
- 人走开后，从他最后所在的位置一圈一圈往外睁开，“一圈圈睁开用时”默认 4 秒（从一角到另一角）。
- 设置 → 识别 → “分区闭眼”可关掉，回到只看最近一个人、整面墙一起闭。
- 调试叠加画出每个人的分区圈和脸宽。演示模式：按住鼠标 = 一个人站在那里，Shift + 按住 = 走到最近，P = 模拟靠近（整面墙）。

## 识别

沿用共享 `../models/face_landmarker.task`，本地 MediaPipe JS／WASM 位于 `vendor/`。CPU 识别在 Web Worker 中执行，最多六人，每次只提交一帧，不阻塞主画面。默认检测 8 Hz，长边最多 640 像素；视频不上传。

用检测到的最大脸宽占画面的比例估计靠近，默认 0.14 闭眼、0.10 以下视为远离；它不是米制测距。靠近确认 0.2 秒，远离／短暂丢失宽容 1.2 秒。任意一人足够靠近即闭眼。阈值需结合摄像头视角、位置和观众距离调整。

## 验证

- 十项 Node 测试通过：近远迟滞、丢失宽容、模拟靠近、种子可复现、双素材混合、挤压重叠上限、中间空洞、闭眼终态、分区只闭身后那片、离开后由近到远睁开。
- 浏览器已验证：素材加载、运行时去底、双眼纹理、WebGL 水幕、随机种子和重新随机按钮、侧栏设置；未见渲染错误。
- 后台真实模型检查页 `tests/worker-check.html` 已成功处理 3 帧空画面，返回 0 张脸，界面心跳持续。
- 未测：真人靠近触发的现场阈值、摄像头旋转后的真人框对齐、手机真机性能与手势。原型会尽量接近参考图气氛，未声称逐像素复现参考图。
