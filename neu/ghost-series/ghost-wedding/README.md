# 3 · 冥婚 v0.1

鬼神系列 03。画面是一面镜子，中间一张凳子。有人坐上去 → 两边的鬼新郎、鬼新娘显形 → 随机做动作；观众头偏向哪边，哪边的鬼凑过来互动，另一边隐去；头回正两个都回来；人离开就消失。

现在的鬼是程序画的“纸扎人”占位，之后换成提供的素材（动作接口不变）。

## 运行

1. 双击 `start.bat`，打开 `http://localhost:8129/`。
2. 画面上没有界面：按 **S** 或连点右上角三下打开设置。**D** 调试、**P** 模拟有人坐下、**←/→** 模拟转头、**R** 重置、**F** 全屏。
3. 需要允许摄像头；画面只在本机处理，不会上传。

## 识别

- 默认用人脸识别判断“凳子上有没有人、头偏向哪边”。
- 远处或低头看不到脸时，可以在设置里打开：
  - **分块检测**：把画面切成小块再找脸，小脸也能找到。
  - **人头检测**（YOLOv8 人头模型）：先找人头，凳子上有人头就算坐下；找到脸以后就不再跑人头检测。人头模型加载失败时自动退回分块检测。
- 人脸置信度、人头置信度都能在设置里手动调。

## 模型

模型放在 `互动demo/models/`（线上是 `ghost-series/models/`），网页自动加载，加载顺序：本地文件夹 → 网站自带 → 官方地址。设置 → 模型 里可以“选择 models 文件夹”导入到浏览器，或“下载模型 zip”。
