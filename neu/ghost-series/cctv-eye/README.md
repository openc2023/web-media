# 2 · CCTV 鬼眼 v0.1

鬼神系列 02。屏幕是一面黑白监控墙：同一个摄像头画面切成 CAM 01–04，每格是一台虚拟云台，各追一个人。有人靠近 → 锁定 → 推到脸 → 推到双眼（眼睛占满画面）→ 眼睛变成黑眼洞 → NO SIGNAL → 回到全景。

## 运行

1. 双击 `start.bat`，打开 `http://localhost:8126/`。
2. 画面上没有界面：按 **S** 或连点右上角三下打开设置。**D** 调试、**P** 模拟有人（两张假脸，没人时也能看整套流程）、**R** 重置、**F** 全屏。
3. 需要联网加载 MediaPipe 模型。

## 流程（每格独立）

| 阶段 | 画面 | 默认时长 |
| --- | --- | --- |
| 待机 | 4 个固定机位：全景、左、右、缓慢扫视；`MOTION SCAN` | — |
| 锁定 | 脸上出现锁定框，`TARGET ACQUIRED`，提示音 | 1.2 s |
| 推到脸 | 只剩脸，`TRACKING · SUBJ xx`，马达声 | 3 s |
| 推到双眼 | 两眼外角占画面宽度 62%，自动抵消歪头 | 3 s |
| 变黑眼 | 眼睛渐变成黑眼洞，一闪一闪，低沉下坠声 | 2.5 s |
| 黑眼停留 | `ANOMALY DETECTED`，偶尔闪一下 | 4 s |
| 信号丢失 | 雪花 + `NO SIGNAL`，然后冷却 5 秒回到待机 | 1.4 s |

- 多人：空闲的格子去追离得最近、还没被别的格子追的人，最多 4 人同时。人走了那格就回到待机。
- 人在但转头超过左右 45° 时，那格停在当前阶段不往下走。
- 镜头是带一点过冲的弹簧运动 + 找焦抖动 + 变焦时模糊，像真的云台。

## 黑眼洞

- 用鬼镜面具贴图（底图 / 血管 GIF）的眼部：按 MediaPipe 官方 UV 用 WebGL 贴到真人眼睛上，只保留两眼附近、边缘渐隐。贴图眼睛位置已自动校准。每人随机一张，设置里可固定。
- **不眨眼**：不用眨眼 GIF；另有“锁眼”——每只眼记住平时睁开的高度，本人眨眼时把眼皮附近的网格撑回去，黑眼洞保持睁开（假脸眨眼对比过）。

## 随机断讯

没在追人的空闲格子时不时 NO SIGNAL / CAMERA OFFLINE 0.6–2.5 秒，配轻静电。人越少空闲格越多，断得越频繁。画面 → 空闲格随机断讯（0 = 关）。

## 设置

- 镜头：摄像头、分辨率、旋转、镜像（监控默认不镜像）、四分屏 / 单画面、时间戳。
- 识别：近距离阈值、角度上限、丢失容忍、防抖、调试。
- 演出：各阶段时长、脸部取景、双眼占画面、跟随速度、找焦抖动、黑眼贴图 / 不透明度 / 范围、音量。
- 画面：每格分辨率（越低越糊越像监控）、对比度、亮度、噪点、扫描线、暗角、撕裂频率。

## 已测 / 未测

- 已测（内置浏览器 + 假脸）：4 格布局、两格同时锁定两张假脸、推到脸、推到眼、黑眼洞出现、无报错。
- **未测：真人效果、真摄像头放大后的清晰度、4 个真人同时**。推到眼睛是数码放大，建议 1080p 以上摄像头、观众离摄像头 1 米以内。
