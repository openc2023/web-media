# 2 · CCTV 鬼眼 v0.1

鬼神系列 02。屏幕是一面黑白监控墙：同一个摄像头画面切成 CAM 01–04，每格是一台虚拟云台，各追一个人。有人靠近 → 锁定 → 推到脸 → 推到双眼（眼睛占满画面）→ 眼睛变成黑眼洞 → NO SIGNAL → 回到全景。

## 运行

1. 双击 `start.bat`，打开 `http://localhost:8126/`。
2. 画面上没有界面：按 **S** 或连点右上角三下打开设置。**D** 调试、**P** 模拟有人（四张假脸，没人时也能看整套流程）、**R** 重置、**F** 全屏。
3. 需要联网加载 MediaPipe 模型。
4. 手机 / 平板：右上角连点三下，或两指按住屏幕 1.2 秒，打开设置；设置里有“全屏 / 退出全屏”和“关闭设置”。画面固定不能滚动、缩放，长按不弹菜单；屏幕保持常亮（浏览器支持时）。

## 流程（每格独立）

| 阶段 | 画面 | 默认时长 |
| --- | --- | --- |
| 待机 | 4 个固定机位：全景、左、右、缓慢扫视；`MOTION SCAN` | — |
| 锁定 | 脸上出现锁定框，`TARGET ACQUIRED`，提示音 | 1.2 s |
| 推到脸 | 只剩脸，`TRACKING · SUBJ xx`，马达声 | 3 s |
| 推到双眼 | 两眼外角占画面宽度 62%，自动抵消歪头 | 3 s |
| 变黑眼 | 眼睛渐变成黑眼洞，一闪一闪，低沉下坠声 | 2.5 s |
| 黑眼停留 | `ANOMALY DETECTED`，偶尔闪一下 | 4 s |
| 信号丢失 | 雪花 + `NO SIGNAL`，然后冷却 5 秒回到待机 | 1.4 s |

- 多人：空闲的格子去追离得最近、还没被别的格子追的人，最多 4 人同时。人走了那格就回到待机。
- **每格随机差异**：每次锁定，那一格随机一套镜头风格，四格不会同步、也不会一模一样：
  - 反应快慢不同（锁定前随机等 0–1.3 秒），所以不会几格同时“嘀”一声锁定。
  - 每个阶段的时长各自随机拉长或缩短（约 ±35–40%）。
  - 取景大小、双眼占画面、跟随速度各不相同；画面不完全居中，镜头带一点歪斜。
  - 约 1/4 的概率只推一只眼（单眼特写，左右随机）；约 1/7 的概率跳过“推到脸”，直接怼到眼睛。
  - 演出 → 镜头 → 每格随机差异（0 = 四格完全一样，默认 0.7）。调试叠加（D）会显示每格当前的风格。
- 人在但转头超过左右 45° 时，那格停在当前阶段不往下走。
- 镜头是带一点过冲的弹簧运动 + 找焦抖动 + 变焦时模糊，像真的云台。

## 远距离（摄像头离人远、脸很小）

- 识别 → 距离 → **远距离检测**：关 / 2×2 / 3×2。打开后画面切成几块（互相重叠）每帧轮流检测一块；被格子追着的小脸（脸宽 < 12%）每帧在他附近裁一块单独跟踪，所以放大后也跟得住。
- 同时把**近距离阈值**调到 0.03–0.05（现在最低 0.02，可直接输入）。
- 实测（合成测试图，1920×1080）：脸宽 10% 和 5.7% 时整幅画面检测不到，3×2 分块四张都找到，四格都能锁定推到黑眼，约 50 fps。
- 限制：**低头看桌面、只露头顶的人检测不到**——模型要看到眼睛鼻子嘴。教室那类俯拍画面里大部分人都在低头，只有抬头看向摄像头的人会被追。摄像头尽量放在人会正面看过来的地方（屏幕旁边、门口正对）。
- 脸小时推到眼睛是很大倍数的数码放大，画面会很糊（监控味更重）。想清楚一点用 4K 摄像头。

## 人头检测（先找人头，再找脸）

- 识别 → 人头检测：关 / nano（12 MB，快）/ medium（104 MB，准，手机别用）。模型是 YOLOv8 人头检测（SCUT-HEAD 教室 / 监控数据训练，trysem/YOLOv8_head_detector，MIT），用 onnxruntime-web 跑（优先 WebGPU，没有就用 CPU）。
- 流程：后台每 0.5 秒找一次人头 → 空闲的格子锁定一个人头 → 每帧在这个头附近裁一块跑人脸关键点 → 抬头看到脸就推到眼睛、变黑眼洞；一直低头时镜头停在头上，显示 `SUBJ xx · FACE NOT VISIBLE`，超过“等抬头最长”（默认 15 秒）就 NO SIGNAL。
- **所有格子都追上有脸的人时，人头检测自动停下**，不再占性能。
- **两种模式**：识别 → 距离 → 远距离检测 是放大切片（只用人脸模型）；人头检测是另一个模型。人头模型加载不了时自动退回放大切片 3×2，调试叠加会显示 `head unavailable → tiles 3x2`。
- 实测（教室俯拍照片，1918×903）：nano 2×2 找到 24–26 个人头（大部分在低头），四格都锁定到低头的人。人脸模型在同一张图上一个都找不到。
- 速度（内置浏览器，较弱的 GPU）：nano 整幅约 150 ms、2×2 约 470 ms；medium 整幅约 640 ms。真机未测。

## 模型文件

- 所有模型放在 `互动demo/models/`（GitHub 上是 `ghost-series/models/`），本地服务器把 `/models/` 映射过去。页面优先读自带文件，读不到再用 Google 官方地址（人头模型没有备用地址）。
- 设置 → 识别 → 模型 里列出这个作品用到的模型，可以单独下载。

## 黑眼洞

- 用鬼镜面具贴图（底图 / 血管 GIF）的眼部：按 MediaPipe 官方 UV 用 WebGL 贴到真人眼睛上，只保留两眼附近、边缘渐隐。贴图眼睛位置已自动校准。每人随机一张，设置里可固定。
- **不眨眼**：不用眨眼 GIF；另有“锁眼”——每只眼记住平时睁开的高度，本人眨眼时把眼皮附近的网格撑回去，黑眼洞保持睁开（假脸眨眼对比过）。

## 随机断讯

没在追人的空闲格子时不时 NO SIGNAL / CAMERA OFFLINE 0.6–2.5 秒，配轻静电。人越少空闲格越多，断得越频繁。画面 → 空闲格随机断讯（0 = 关）。

## 设置

- 镜头：摄像头、分辨率、旋转、镜像（监控默认不镜像）、四分屏 / 单画面、时间戳。
- 识别：近距离阈值、角度上限、丢失容忍、防抖、调试。
- 演出：各阶段时长、脸部取景、双眼占画面、跟随速度、找焦抖动、黑眼贴图 / 不透明度 / 范围、音量。
- 画面：每格分辨率（越低越糊越像监控）、对比度、亮度、噪点、扫描线、暗角、撕裂频率。

## 已测 / 未测

- 已测（内置浏览器 + 假脸）：4 格布局、两格同时锁定两张假脸、推到脸、推到眼、黑眼洞出现、无报错。
- **未测：真人效果、真摄像头放大后的清晰度、4 个真人同时**。推到眼睛是数码放大，建议 1080p 以上摄像头、观众离摄像头 1 米以内。
